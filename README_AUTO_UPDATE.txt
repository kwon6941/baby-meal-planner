아기 식단 플래너 - 자동 레시피 DB 업데이트 버전

- 앱은 시작할 때 recipes.json을 최신 상태로 불러옵니다.
- GitHub Actions가 매주 일요일 오전 4시(Asia/Seoul)에 공개 유아식 레시피를 확인합니다.
- 새 레시피가 발견되면 recipes.json을 자동 갱신하고 GitHub에 커밋합니다.
- Netlify를 이 GitHub 저장소와 연결하면 커밋 후 사이트가 자동 재배포됩니다.
- 현재 자동 수집기는 만개의레시피 공개 검색/레시피 페이지를 대상으로 하며 최대 300개까지 유지하도록 설정되어 있습니다.
- 레시피 링크 자체는 원문 사이트로 연결되며 앱 안에 원문 본문을 복제하지 않습니다.
- 자동 수집은 외부 사이트 구조 변경이나 접근 제한에 따라 실패할 수 있습니다.
